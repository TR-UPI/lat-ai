LAT AI — инструкция независимым проверяющим
Это пустой пакет для реальных работ. Результатов модели и авторских меток в нём нет.

L1.types.1
print("3" + "2")
Критерии:
1. Указано, что каждый из двух операндов — строка (str, текст). Тип может быть назван отдельно для каждого операнда или прямо в описании их соединения.
2. Объяснено, что + соединяет строки, а не складывает числа.
3. Указан точный вывод: 32.

L1.condition.1
x = 2
if x == 2:
    print("да")
else:
    print("нет")
Критерии:
1. Объяснено, что x равно 2, поэтому условие x == 2 истинно.
2. Указано, что выполняется ветка if, а else пропускается.
3. Назван результат вывода программы: да. Кавычки и имя print не обязательны. Отрицание выполнения else не является отрицанием этого вывода.

L2.range.1
for i in range(2, 5):
    print(i)
Критерии:
1. Перечислены ровно значения 2, 3, 4, без лишних чисел.
2. Объяснено, что правая граница 5 не входит в range.
3. Верно описан вывод: каждое из чисел 2, 3, 4 напечатано на своей строке. Достаточно описать сами строки результата; слова print и цикл не обязательны.

L2.accumulator.1
s = 0
for i in range(1, 4):
    s = s + i
print(s)
Критерии:
1. Объяснено, что s создаётся равной 0 один раз до цикла, а не сбрасывается внутри.
2. Прослежено накопление: после прибавления 1, 2, 3 сумма равна 1, 3, 6; итог 6.
3. Объяснено, что print без отступа находится после цикла и печатает итог один раз.

Каждый из двух преподавателей размечает все три критерия независимо, не видя оценки второго и модели.
true — ученик достаточно объяснил критерий; false — неверно, неполно либо прямо противоречит себе по этому критерию.
Не переносить ошибку между независимыми критериями; не домысливать отсутствующее из правильного кода.
Если сама рубрика неоднозначна, отметить ambiguous_rubric и пояснить: не менять молча метку.
После двух независимых листов согласовать расхождения отдельно, сохранив оба первоначальных решения и причину.
Не загружать результаты модели до завершения исходной разметки. Преподавательская оценка остаётся основной.
Текстовый якорь модели не равен доказательству: после теневого прогона отдельно проверить все положительные цитаты.
Правила трактовки самоисправлений, неявных следствий и частичных объяснений утвердить до прогона.
