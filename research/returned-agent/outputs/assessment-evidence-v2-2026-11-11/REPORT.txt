РЕШЕНИЕ
Принят экспериментальный оценщик evidence-v2h-verified. Он извлекает
непрерывные цитаты из исходного ответа, указывает конкретный противоречащий
фрагмент по каждому критерию и выполняет второй проход на исходном ответе.
При расхождении хотя бы одного критерия оценка не выдаётся. Это existing
unavailable/invalid_output, а не ноль, не частичный балл и не усреднение.

Новый frozen32:26 верных оценок с достаточными цитатами,6 отказов,0 ошибочных
выданных оценок относительно авторской разметки. Покрытие автооценкой81,25%.
Отказы не посчитаны правильными. Это не результат «32/32» для принятого H.
Смысловая проблема не закрыта полностью: на известных96 остались2 частичные
цитаты; правильные перефразировки могут приводить к отказу; обе инструкции
одной модели способны ошибиться одинаково. Преподавательского допуска нет.

ЧТО ИЗМЕНЕНО
- Первая модельная схема: для каждого критерия start/end/counter с ID S1…Sn.
  Диапазон допускает несколько предложений; цитата извлекается по позициям
  из исходной строки, сохраняя пробелы, CRLF и повторяющиеся фрагменты.
- Конкретный counter заменяет общий флаг противоречия. Проверяется весь
  ответ; ошибка по одному критерию не должна отменять остальные.
- Уточнены инструкции о пропущенных фактах, отрицании, порядке фактов и
  рубрики для типов строк/построчного range. Балл считает прежний backend.
- Второй проход использует замороженные прежние evidence-v1 промпт/рубрики.
  Он не видит предложение первого прохода. Цитаты второго прохода никогда
  не выдаются ученику; сравниваются только три решения по критериям.
- Два вызова выполняются последовательно внутри прежней общей очереди и
  одного AbortSignal/бюджета. Unknown POST не повторяется. Токены обоих
  вызовов суммируются; потеря/обрезка проверки не выпускает оценку.
- Внешний формат checks/evidence/rubric_version=local-assessment-v1 сохранён.
  Новая assessment_revision входит в прежний fingerprint AI-журнала.
  Исторические оценки автоматически не пересчитываются.
