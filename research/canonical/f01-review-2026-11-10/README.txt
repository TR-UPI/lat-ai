LAD AI — переносимый пакет проверки F01, 10.11.2026

Это исследовательское дополнение, не новая версия приложения Windows.
Начните с DECISIONS.txt — что решено, открыто и запрещено менять.
TEACHER_REVIEW.txt — незаполненный короткий лист T01.
METHOD_NOTES.txt — границы статистики и автоматической проверки.

Распакуйте ZIP полностью. Нужен Python 3.10+ (только стандартная библиотека).
В терминале из папки пакета выполните одну команду:
    python run_all.py
Или укажите путь явно:
    python run_all.py --bundle "D:\Проверка LAD AI"
Если команда python не настроена, укажите полный путь к python.exe.
Можно использовать runtime\python\python.exe из полного Windows-комплекта.
Успех: exit 0 и JSON passed=true. Ошибка: exit 1 и VALIDATION FAILED.

Утилита не изменяет пакет, не запускает модель, не пересматривает оценки,
не выполняет код из вопросов и не пишет в canonical roadmap/STATUS.
Это единая точка проверки опубликованных артефактов, не автоматическая
замена всех ручных стадий исходного исследования.

Исторические REPORT/REVIEW/FINAL_REVIEW сохранены в historical без правок;
для интерпретации применяйте уточнения DECISIONS/METHOD_NOTES.
Первичные/final оценки, adjudication, protocol и frozen inputs сохранены.
Старые скрипты с машинными путями сюда не включены; они остаются в старом
неизменённом архиве. MANIFEST содержит SHA256/размер каждого файла пакета,
кроме самого MANIFEST. Проверки не доказывают педагогическое качество.

В отдельном Windows-комплекте после START.cmd интерфейс находится здесь:
http://127.0.0.1:5173/#/courses
Django admin в локальном профиле ai_local отключён: /admin/ не откроется.
Маршрут /admin/ есть в основном Django-проекте, но не в тестовой сборке.
