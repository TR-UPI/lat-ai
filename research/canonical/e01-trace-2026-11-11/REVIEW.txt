Reviewed invariants
- Loop binding captures the actual current variable value before overwriting
  it, including mutations made by the preceding body. Assignment RHS is
  evaluated before its target is replaced. Print events preserve order.
- Source indices are assigned before blank lines are filtered. Editor context
  passes the complete normalized code block; selection only marks focus.
- Entire syntax is parsed before execution. Runtime failure and command-limit
  failure return null, so no partially accumulated trace escapes.
- Accepted traces contain at most 100 executed simple/body commands plus
  20 loop bindings (or one empty-loop marker). Full event data is bounded.
- Visible rendering permits at most 12 events and 1500 event-text characters;
  bounded header/footer overhead keeps total below 1800. Shown/total, omitted
  count, and complete flag consistently disclose a truncated prefix.
- Events remain opt-in for state APIs. Only explain ledgers request and render
  them. Explain ledger hashes include an explicit renderer version; hints use
  the original hash input. Existing fact generation remains otherwise intact.
- Paired report documents 16/57 historical traces (14 complete, 2 partial),
  and 17/24 development traces (16 complete, 1 partial), without asserting
  unsupported inputs have causal traces or assigning new adequacy scores.
