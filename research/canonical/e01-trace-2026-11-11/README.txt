LAD AI — E01 trace candidate, 11.11.2026

Это самостоятельный offline-эксперимент для разработчика/оценщика,
а не установочный пакет Windows и не допуск учеников. Текущий сайт не меняется.
REPORT.txt — результат и ограничения. PAIRS.txt —81 пара «до/кандидат».
REVIEW.txt — независимое техническое ревью. LEDGER.txt — решения по ходу.

Распакуйте в папку с правом записи. Нужны Node.js22+ и Python3.10+;
внешних библиотек и модели не требуется. Из папки пакета:
    python run_all.py --verify-only
проверяет SHA256 всех файлов и замороженные входы без изменения пакета.
    python run_all.py
сначала проверяет целостность, затем335 baseline и367 candidate тестов.
Можно указать полный путь к python.exe из полного Windows-комплекта.

baseline/ — исходный модуль и тестовые фикстуры; candidate/ — эксперимент.
cases.json зафиксирован до изменения; все24 случая — authored development.
Проверки на временных файлах не обращаются к рабочей БД/живой модели.
MANIFEST.json защищает от повреждений; не удостоверяет авторство.

Для повторной генерации сравнения сначала сделайте копию пакета:
    node compare.mjs
запишет pairs/comparison/PAIRS заново; reference.py проверит только заранее
зафиксированные поддерживаемые авторские программы CPython. После генерации
часть файлов намеренно изменится и прежний manifest перестанет совпадать.
Не используйте эти скрипты как исполнение присланного учеником кода.

Не переносите два изменённых файла в работающую сборку автоматически:
полные модельные ответы/HTTP/бюджет8–10с для кандидата ещё не проверялись.
README, Python/Node/model для запуска сайта находятся в прежнем отдельном
LAD-AI-Windows-tester-2026-11-10.zip. Его локальная Django admin отключена.
