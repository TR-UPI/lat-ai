Алгебра: линейные и квадратные уравнения

Линейное уравнение с одной переменной имеет вид ax + b = 0. Если a не равно нулю, уравнение имеет единственное решение x = -b/a. Для решения можно переносить слагаемые из одной части в другую, меняя знак, и делить обе части на одно и то же ненулевое число. Проверка выполняется подстановкой найденного значения в исходное равенство.

Пример: 3x + 6 = 18. Вычтем 6 из обеих частей: 3x = 12. Разделим обе части на 3: x = 4. Проверка: 3 · 4 + 6 = 18. Ответ верный.

Квадратное уравнение имеет вид ax² + bx + c = 0, где a не равно нулю. Дискриминант вычисляется по формуле D = b² - 4ac. Если D больше нуля, существуют два различных действительных корня. Если D равен нулю, есть один действительный корень кратности два. Если D меньше нуля, действительных корней нет. Формула корней: x₁,₂ = (-b ± √D)/(2a).

Пример: x² - 5x + 6 = 0. Здесь a = 1, b = -5, c = 6. Получаем D = 25 - 24 = 1. Корни: x₁ = (5 - 1)/2 = 2 и x₂ = (5 + 1)/2 = 3. Проверка: 2² - 5 · 2 + 6 = 0 и 3² - 5 · 3 + 6 = 0.

Важно не терять знак коэффициента b и не забывать скобки при подстановке отрицательных чисел. Чтобы найти количество действительных корней квадратного уравнения, достаточно сначала вычислить дискриминант и сравнить его с нулём.
