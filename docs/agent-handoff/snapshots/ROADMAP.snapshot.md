## Как пользоваться

Этот файл — единый актуальный порядок работ и место для предложений из ревью. **STATUS.md остаётся единственным журналом фактически выполненной работы**, а отчёты версий — неизменяемыми доказательствами. При расхождении старого плана и этого файла текущий порядок берётся отсюда; требования пользователя сохраняют приоритет.

Статусы задач: **Очередь → В работе → Проверка → Готово**. Дополнительно: **Ожидание** с конкретной зависимостью; **Отложено** с условием возвращения. «Готово» требует результата и ссылки на проверку. S01, R01, H01, U01/U02 и интеграция I01 реализованы и проверены в ограниченном контуре; остальные задачи очереди не закрыты. Подготовка материалов для людей не считается их приёмкой.

P0 — блокирует соответствующий режим показа. P1 — следующая очередь подготовки демо. P2 — после показа. При нехватке времени отключаем неподтверждённую функцию и явно сужаем сценарий; критерий не снижаем задним числом.
